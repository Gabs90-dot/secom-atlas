\# Mobile UX Roadmap



\## Obiettivo



Il mobile di ATLAS deve essere pensato per il tecnico sul campo.



Non deve essere una copia ridotta del desktop.



\## Utente principale



Tecnico operativo.



\## Deve poter fare



\* vedere ticket assegnati

\* aprire dettaglio ticket

\* chiamare cliente o referente

\* aprire mappa

\* leggere contratto/sede

\* aggiungere note

\* aggiungere attività visibili al cliente

\* allegare foto

\* registrare materiali usati

\* compilare bolla

\* far firmare il cliente

\* chiudere intervento



\## Non deve essere centrale su mobile



\* gestione utenti

\* amministrazione sistema

\* dashboard complesse

\* import GLPI

\* gestione massiva clienti

\* configurazioni avanzate



\## Principi UI



\* pochi pulsanti

\* azioni grandi

\* leggibilità alta

\* niente tabelle enormi

\* card operative

\* bottom navigation

\* stato ticket sempre visibile

\* azione primaria evidente



\## Flusso ideale tecnico



1\. Apro ATLAS mobile.

2\. Vedo i ticket di oggi.

3\. Apro ticket.

4\. Vedo cliente, indirizzo, contatto, descrizione.

5\. Aggiungo attività.

6\. Aggiungo materiali.

7\. Genero/compilo bolla.

8\. Raccolgo firma.

9\. Chiudo intervento.
